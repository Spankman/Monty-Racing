## Diagnostic interpretation

The frozen engines are market-conditional. Distinguish the normalized market baseline, conditional feature correction, market-temperature-only counterfactual, full-model calibration effect, static log-market coefficient, observed versus imputed values and within-race constant cancellation. The stored decomposition satisfies:

`point EV = (model probability - market probability) * selected odds + (1 / overround - 1)`.

The second term is normalization alone; it is not predictive advantage. Prices remain subject to full-field, named-bookmaker, timestamp, scratchings and independent verification gates. Conditional correction probabilities are explicitly **not independently trained form predictions**. Linear term attribution is not causal feature importance. Compute paired out-of-sample loss differences and uncertainty before claiming genuine uplift.

## Reproducible research contracts

* `IndependentFormLearner` defines fit/predict/save boundaries for future separate research implementations. Exclude current market and result columns; verified earlier features and labels are mandatory.
* `market_baseline` normalizes a complete valid race market, as a comparative baseline only; integrity approval remains separate.
* `benter_combination` evaluates supplied earlier-fitted log-probability coefficients and requires independent-form provenance. This implements a mathematical comparison interface, not a reproduction of the full published estimation methodology.
* `adaptive_combination` accepts earlier-validated, bounded race-wide form weights with complete distributions. No automatically invented confidence weighting.
* `calibrate` accepts an earlier-fitted temperature. `ablate` returns a copy for controlled studies; it never modifies frozen artifacts.
* `walk_forward` requires complete race/date identity, explicit pre-jump feature availability, verified as-of provenance, strict train/calibration/test chronology and result availability before earlier fitting cutoffs. No shuffled runner split, later-result leakage or silent timestamp inference.
* The immutable experiment registry records SUCCESS, NULL, NEGATIVE or BLOCKED outcomes, source/artifact provenance and research-only status. Registration does not constitute model approval.

Use the existing prospective metric and roughie audit modules for paired race-level log loss/Brier/rank and fixed odds-band analysis ($10–19.99, $20–39.99, $40–59.99, $60+), sample sizes, calibration, uncertainty and winner concentration. Report unavailable labels/place terms and verified feature coverage. Neither an interface nor synthetic tests establish historical or prospective performance.
